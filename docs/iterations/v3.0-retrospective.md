# V3.0 Retrospective

## Problem

产品只能回答“家里有什么可以做”，无法覆盖用户决定外出就餐类型时的同一类选择困难。

## Why V3.0

V3.0 用最小第二场景验证「今天吃什么」能否从做饭工具发展为双场景决策产品，同时不引入真实餐厅数据的复杂度。

## What Changed

- 首页增加 Home / Eat Out 双入口；
- Eat Out 支持轻量偏好、完全随机或指定候选随机；
- 增加餐饮类型盲盒、换一个和确认结果；
- README 重新聚焦双场景价值、演进证据与产品边界。

## What Stayed Out

定位、地图、商圈、真实餐厅、POI、外部 API、登录、AI 与后端均未进入本轮。

## Validation

- 核心与浏览器测试 165/165；
- 部署 smoke 13/13；
- 发布 preflight 14/14；
- 覆盖 320 / 390 / 768 / 1440px、Reduce Motion、键盘基础操作和控制台错误。

## Remaining Unknowns

- 用户是否能更快理解并选择 Home / Eat Out；
- 轻量条件是否足够，还是餐饮类型仍然过宽；
- 换一个的频率与原因；
- 外出结果是否真正促成一次线下用餐决策。

## Next Evidence Needed

优先观察场景选择完成率、获得结果用时、换一个频率与确认率。下一版本号和实现方向应在获得证据后决定，本复盘不自动定义 V4.0。

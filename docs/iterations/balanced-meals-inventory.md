# 多人菜单、健康餐与库存调整

## 问题

单道菜按人数放大，不能体现多人用餐的荤素搭配；健康餐缺少整顿热量约束；库存消耗只能经过制作流程。

## 本次改动

- 正常正餐支持输入 1–6 人，组合人数道或多一道菜，包含蔬菜、蛋白质和必要的主食。
- 健康餐按用户选定的每人估算热量上限筛选整顿菜单；食材需求跨菜品合并后核对库存和扣减。
- 库存可选择批次直接扣减，删除批次需二次确认；旧 LocalStorage Schema v2 数据继续可用。
- 从参考图片挑选可写出食材与步骤的家常菜，扩充本地菜谱；外出就餐增加更多餐饮类型。

## 边界与验证

热量、价格和做法为演示估算，不提供精确营养建议。严格库存下无可行菜单时说明原因并允许调整条件。验证覆盖人数与菜品数、热量、批次操作、V2 购买时长、LocalStorage、响应式和控制台错误。
